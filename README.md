# MooinTech DFU AI

This repository contains the learning and implementation work for the MooinTech Diabetic-Foot AI project.

## Current Stage

### Week 1 — Image Representation Foundations

This week focuses on understanding digital images as numerical data before moving to later computer vision stages.

Topics covered:

- Pixels
- NumPy arrays
- Image shape
- Height and Width
- Channels
- RGB channels
- HWC and CHW layouts
- dtype
- Bit depth
- Numeric range
- uint8 arithmetic and overflow
- Basic image metadata inspection
- EXIF presence

## Structure

- `notebooks/`: Jupyter notebooks for image representation experiments and documentation.
- `scripts/`: Python utility scripts for image inspection and related foundational tasks.
